# MudBlazor Component Implementation Guide: MudExitPrompt\n\n## Overview\n\nThis guide details the implementation pattern for the `<MudExitPrompt>` component, which intercepts navigation attempts to warn the user about unsaved data, as seen in MudBlazor v9.x documentation.\n\n## Component Usage\n\nThis component should be placed on the page that needs to guard against accidental navigation.\n\n```razor\n<MudExitPrompt Disabled=\"_isDisabled\" UseNativePrompt=\"_useNativePrompt\" />\n```\n\n## Parameters\n\n*   **`Disabled`**: A `bool` parameter. If set to `true`, the prompt will never appear, bypassing the warning.\n*   **`UseNativePrompt`**: A `bool` parameter. If `true`, the browser's native confirmation dialog will be used instead of the built-in MudBlazor dialog.\n\n## Testing Implementation (Example from Docs)\n\n```razor\n<MudExitPrompt Disabled=\"_isDisabled\" UseNativePrompt=\"_useNativePrompt\" />\n\n<MudStack Spacing=\"2\">\n    <MudSwitch Label=\"Disabled\" @bind-Value=\"_isDisabled\" Color=\"Color.Primary\" />\n    <MudSwitch Label=\"Use native prompt\" @bind-Value=\"_useNativePrompt\" Color=\"Color.Primary\"/>\n    <MudButton Variant=\"Variant.Outlined\" Color=\"Color.Primary\" Href=\"/components/exitprompt\">Test navigation</MudButton>\n</MudStack>\n```\n\n*Note: In a production environment, the actual interception logic should hook into the `OnBeforeUnload` event or the Blazor Router's navigation guard.*
